# Ejercicio 6. Swap Variables Valor
## Problema🖥:
Se deberá crear una funcion la cual imprima intercambie el valor de dos variables númericas sin usar una tercera variable o funciones propias del lenguaje que permita realizar esta accion.
```  
    Input: 
        x = 10;
        y = 5;
    
    Output:
        x = 5;
        y = 10;
```
